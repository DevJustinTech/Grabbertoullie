## 2024-06-05 - Optimize SSRF Validation DNS Lookups
**Learning:** Attaching a custom security event_hook (like check_url_hook) to httpx.AsyncClient that executes DNS validation (e.g., via getaddrinfo) before every request inherently defeats connection pooling by forcing a new DNS lookup each time. This creates a significant performance bottleneck for repeated API calls to the same domain.
**Action:** Use a time-bound LRU cache (e.g., OrderedDict with a short TTL) inside the SSRF validation function to cache resolved DNS records, preventing redundant lookups while maintaining security properties.
